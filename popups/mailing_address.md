## Mailing Address

Enter the mailing address exactly as it should appear on an envelope.

- **Address Line 1** contains the primary delivery address (street address, PO Box, RR, or General Delivery).
- **Address Line 2** is optional and is used for apartment/unit numbers, suites, or stations.
- Enter the **City**, **Province/State**, **Postal/ZIP Code**, and **Country Code** in their respective fields.  


**Examples:**  
| Address Type | Address Line 1 | Address Line 2 |
|--------------|----------------|----------------|
| Street Address | 123 Main St | *(leave blank)* |
| Apartment/Unit | 123 Main St | Apt 203 |
| Suite/Office | 123 Main St | Suite 500 |
| PO Box | PO Box 123 | *(leave blank)* |
| Rural Route | RR 2 | *(leave blank)* |
| PO Box with Station | PO Box 123 | Station A |
