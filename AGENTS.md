# Project Instructions for Posit Assistant

## Coding Conventions

- Variable names must be snake_case
- Function names must be lower case snake_case
- Use R's native pipe operator (`|>`) when chaining commands
- Use tidyverse functions where possible
- Annotate code when using regex functions
- Use double quotes for variable names and strings
- Use bslib functions and UI elements when developing Shiny modules and code
- Code indentations should be 2 spaces
- Provide terse, concise and clear explanations when asked to explain code
- Do not over-engineer solutions; keep them simple and efficient
- Do not suggest additional steps unless asked to do so
